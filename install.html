iPhone／iPad：安裝描述檔 推薦

下載「鬧熱牌局」描述檔
  1. 請用 Safari 開這一頁，點上面的按鈕，選「允許」。
  2. 畫面顯示「已下載描述檔」後，打開 設定 App，點最上方的「已下載描述檔」
    （或 設定 → 一般 → VPN 與裝置管理）。
  3. 點「安裝」，輸入手機密碼，再按一次「安裝」。
  4. 回到主畫面，就會看到「鬧熱牌局」圖示，點開即可全螢幕遊玩。
描述檔只會在主畫面加入一個網頁捷徑（Web Clip），不會安裝任何程式、不會管理或讀取你的手機。因為沒有付費簽章，安裝畫面會顯示「未驗證」，屬正常現象。不想要時，到 設定 → 一般 → VPN 與裝置管理 → 鬧熱牌局 → 移除描述檔 即可；或直接長按圖示刪除。
請務必使用 Safari；在 Chrome、LINE、Facebook 內建瀏覽器中點下載通常沒有反應。
如果點了沒跳出「允許」：Safari 可能會改成一般檔案下載（網址列旁出現下載圖示）。請打開「檔案」App → 「下載項目」，點一下 naojiat.mobileconfig，再到「設定」→「已下載描述檔」安裝。仍不行的話，用下方「Safari 加入主畫面」，效果一樣。

iPhone／iPad：Safari 加入主畫面

  1. 用 Safari 打開 遊戲首頁。
  2. 點下方的「分享」按鈕（方框加向上箭頭）。
  3. 往下滑，點「加入主畫面」，再點「新增」。
這個方法不需要描述檔，效果相同。

Android：安裝 App

  1. 建議使用 Chrome 開啟本頁。
  2. 點上面的按鈕，選「安裝」。
  3. 如果按鈕沒有反應：點右上角 ⋮ 選單 → 「安裝應用程式」或「加到主畫面」。
